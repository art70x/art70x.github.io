# art70x.github.io

A responsive personal portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. The featured project cards are included in the HTML, so the page remains useful if the optional GitHub API request is unavailable.

## Project files

- `index.html`: page content, metadata, navigation, and project links
- `style.css`: layout, responsive styles, and reduced-motion handling
- `script.js`: current year and optional GitHub repository metadata
- `assets/`: brand marks and favicon images

## Deployment

The site is designed for static hosting, including GitHub Pages. No build step is required.
