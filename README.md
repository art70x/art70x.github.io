# art70x — Frontend Developer Portfolio

A responsive personal portfolio showcasing frontend development projects, practical web tools, and interface experiments. Built with semantic HTML, CSS, and vanilla JavaScript, and deployed with GitHub Pages.

Live site: https://art70x.github.io/

Overview

This repository contains the source code for my personal portfolio. It introduces my work, highlights selected projects, describes my current technology stack, and links to my developer profiles.

The site is designed to work as a lightweight static website without a build step or backend server.

Featured projects

- "Plain2TeX" (https://github.com/art70x/Plain2TeX) — Convert plain-text mathematical expressions into typeset LaTeX.
- "json-builder" (https://github.com/art70x/json-builder) — Construct and inspect JSON objects and arrays through a visual interface.
- "Vuetrix" (https://github.com/art70x/Vuetrix) — A Vue 3 and TypeScript starter template for frontend projects.
- "JSONotations" (https://github.com/art70x/JSONotations) — Explore a concept for visualizing and inspecting structured JSON data.

Visit the "live portfolio" (https://art70x.github.io/) to see the selected projects and explore the "GitHub profile" (https://github.com/art70x) for more work.

Built with

- HTML5 for semantic page structure
- CSS3 for responsive layouts, styling, and reduced-motion support
- Vanilla JavaScript for small interactive enhancements
- GitHub REST API for optional repository metadata
- GitHub Pages for static hosting

Features

- Responsive portfolio layout
- Selected project cards with direct repository links
- About, technology-stack, and contact sections
- Keyboard skip link and visible focus styles
- Reduced-motion support
- Static project-card content that remains available if the optional GitHub API request fails
- No build step or package installation required

Run locally

1. Clone or download this repository.
2. Open "index.html" in a browser.

The page is static, so no development server is required for basic local viewing.

Deployment

This site is intended for GitHub Pages.

The published site is available at:

https://art70x.github.io/

The HTML, CSS, JavaScript, and assets are served as static files. No compilation or server-side runtime is required.

Accessibility and progressive enhancement

The site includes a skip link, keyboard focus styling, responsive CSS, and a reduced-motion preference rule.

Featured projects are present in the HTML before JavaScript runs. The optional GitHub API enhancement can update repository information, but the page does not rely on a successful API request to show its core project cards.
